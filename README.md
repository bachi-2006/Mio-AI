# 🤖 Mio AI (Mio AI Nexus)

Mio AI is a multi-version generative artificial intelligence project featuring custom web interfaces, NLP integrations, and rich documentation.

---

## 📂 Project Structure & Versions

### 1. [Vercel V1](file:///c:/Kaboom!/Projects/Mio%20AI/Vercel%20V1)
- **Tech Stack**: Next.js 15, React 19, TailwindCSS, Lucide Icons, Shadcn UI, Framer Motion, Google Generative AI (`@google/generative-ai`), Gradio (`@gradio/client`).
- **Description**: Next.js web client containing rich components for AI chat prompts, Gradio model endpoints integration, and dynamic layouts.
- **To Run**:
  ```bash
  cd "Vercel V1"
  npm install
  npm run dev
  ```

### 2. [Lovable V2](file:///c:/Kaboom!/Projects/Mio%20AI/Lovable%20V2/mio-ai-nexus-main)
- **Tech Stack**: Vite, React, TypeScript, TailwindCSS, Shadcn UI, Supabase.
- **Description**: Refactored frontend workspace created via Lovable.dev, integrating Supabase DB/authentication.
- **To Run**:
  ```bash
  cd "Lovable V2/mio-ai-nexus-main"
  npm install
  npm run dev
  ```
